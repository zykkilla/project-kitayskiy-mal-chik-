# project-kitayskiy-mal-chik-
Пухненков Егор, Давлятов Булат, Кашапов Рафаэль
Реализация компактной файловой системы с базовыми операциями CRUD (Create, Read, Update, Delete), работающей в рамках одного физического файла.

## 🔍 Общее описание
Файловая система хранит все данные в едином файле (data.fs по умолчанию), используя структурированный текстовый формат:

[имя_файла1]
[содержимое_файла1]
/
[имя_файла2]
[содержимое_файла2]
/
...
## 📌 Ключевые особенности:
+ Хранение всех данных в одном файле

+ Поддержка многострочного содержимого

+ Гарантия целостности данных при операциях

+ Интуитивный интерфейс командной строки

## ⚙️ Технические характеристики
📏 Ограничения системы:
Максимальный размер содержимого файла: 4 КБ (4096 символов)

Поддержка только плоской структуры (без подкаталогов)

Отсутствие системы прав доступа

## 📁 Формат хранения:
Строка с именем файла

Произвольное содержимое (одна или несколько строк)

Разделитель / на отдельной строке

## 🛠 Функциональные возможности
## 📋 Основные операции:
Функция	Описание
'''
fs_init()	Инициализация файловой системы
fs_create()	Создание нового файла
fs_read()	Чтение содержимого файла
fs_update()	Обновление содержимого
fs_delete()	Удаление файла
fs_shutdown()	Корректное завершение работы
'''
## ⌨️ Командный интерфейс:
Доступные команды:
'''
 создать <имя> <текст>  - Создать новый файл
 прочитать <имя>        - Показать содержимое
 обновить <имя> <текст> - Изменить содержимое
 удалить <имя>          - Удалить файл
 помощь                 - Показать справку
 выход                  - Завершить программу
 '''
## 🚀 Запуск и использование
Сборка программы:
bash
gcc -o fs filesystem.c main.c
Запуск системы:
bash
./fs
Пример сеанса работы:
создать документ.txt "Привет, мир!"
Файл 'документ.txt' создан

прочитать документ.txt
Содержимое 'документ.txt':
Привет, мир!

обновить документ.txt "Новое содержимое"
Файл 'документ.txt' обновлен

удалить документ.txt
Файл 'документ.txt' удален

выход
